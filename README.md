# Triple Espresso

## Descripción del proyecto

Triple Espresso es una página web para una cafetería que presenta información sobre el establecimiento, sus horarios y ubicación.

Incluye un formulario para reservar mesas, con campos para el nombre, número de comensales, fecha, hora y correo electrónico. También contiene enlaces de navegación y una sección de redes sociales.

## Tecnologías y técnicas utilizadas

- HTML5 para estructurar el contenido de la página.
- CSS3 para diseñar y dar estilo a los elementos.
- Flexbox para organizar y alinear componentes.
- Posicionamiento relativo y absoluto para ubicar elementos decorativos e imágenes.
- Metodología BEM para organizar las clases CSS del formulario y el pie de página.
- Pseudoclases CSS y transiciones para crear efectos interactivos.
- Validación de formularios mediante atributos HTML.
